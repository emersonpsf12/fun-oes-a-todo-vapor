Projeto integrador BCC

Jogo educacional feito em C com a biblioteca Allegro 5.

O jogo mostra dados de um gráfico e o jogador precisa montar o gráfico certo em um plano cartesiano.

#Controles
Clique esquerdo: marca um ponto.
Clique direito: apaga o último ponto.
ESC: fecha o jogo.

Para compilar precisa ter o MinGW e o Allegro 5 instalados.

gcc main.c -o jogo -lallegro - lallegro\_primitives -lallegro\_font -lm
